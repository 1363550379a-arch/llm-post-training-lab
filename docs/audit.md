训练保存采用 PEFT adapter；RM 另存 score 头，PPO 单存 value_head.pt。DPO 与 PPO 的适配器必须加载到偏好 SFT 合并基座，GRPO 必须加载到数学 SFT 合并基座。所有权重、原始数值和图表均保留。原运行以 save_strategy=no 为主，目标项目中未找到 trainer_state.json；相邻项目的单步训练与本报告无关。

检验范围为历史日志、保存张量、数据交叉检查和 CPU 轻量测试。四项 pytest 测试覆盖数值解析、错误答案、GAE 终止条件与回报，以及本地随机初始化微型 Qwen2 的 CPU 策略更新（验证 B 张量更新后非零）。历史环境为 Windows/CUDA，本次未验证 Linux/ROCm 或修复后的 GPU 训练。优先复核 PPO 第一次有效策略更新前后的参数差、ratio 分布及显存。更新时保留训练模式并关闭 dropout。需要重新训练的结果标为待验证。
